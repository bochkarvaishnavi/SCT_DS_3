SkillCraft Technology Internship - Task 03

Interactive Visualization Dashboard

Objective

Create an interactive dashboard using Power BI to analyze employee attrition and identify factors affecting employee turnover.

Dataset

IBM HR Employee Attrition Dataset

Tools Used

- Power BI Desktop
- Microsoft Excel

Dashboard Features

- Total Employees Card
- Attrition Count Card
- Attrition by Department
- Attrition by Gender
- Attrition by Age Group
- Attrition by Job Role
- Attrition by Marital Status
- Attrition by Education Field
- Interactive Slicers (Department, Gender, Age)

Key Insights

- Analyzed employee attrition across different departments.
- Identified attrition trends based on gender and age groups.
- Compared attrition among various job roles.
- Studied the impact of education field and marital status on attrition.
- Created interactive filters for better data exploration.

Outcome

Developed an interactive HR Analytics Dashboard that helps understand employee attrition patterns and supports data-driven decision making.
